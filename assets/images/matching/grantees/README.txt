Matching Grants — grantee photos
================================

Drop one photo per project into this folder, using the EXACT filename below.
As soon as the file exists it replaces the coloured gradient + initials on the
matching card in matching.html automatically. If a file is missing, that card
simply falls back to the gradient — nothing breaks.

each photo goes to the right filename so they don't get swapped.

Tips
----
- .jpg is expected. If you only have .png, either rename it to .jpg or tell me
  and I'll switch that card to .png.
- Landscape photos work best (the card image area is wide and short, ~4:3).
  Larger is fine — the image is cropped to fill and centred.
- Keep file sizes reasonable (ideally under ~300 KB each) so the page stays fast.
