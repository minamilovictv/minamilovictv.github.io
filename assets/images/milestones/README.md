# Milestone gallery images

Drop the milestone photos here to replace the navy placeholder panels in the
**Key Milestones** section on `about.html`.

A missing file is not an error — the card falls back to a clean navy panel, so
the timeline always looks finished. Add photos whenever they become available.

## Format

Landscape, at least **680 × 336 px** (the card renders them at 340 × 168 and
crops to fill). JPG.

## Naming

The twelve original cards keep their sequential names (`milestone-01.jpg` …
`milestone-12.jpg`). Everything added afterwards is named by date and subject,
which makes it obvious which photo belongs to which card:

    milestone-YYYY-MM-short-slug.jpg

## Adding a milestone

`<ol class="ms-row">` for its year, then point its `src` at a new file here.
