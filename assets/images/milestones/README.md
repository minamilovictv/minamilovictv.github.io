## Recommendations

- **Aspect ratio:** landscape, ~2:1 (e.g. 680×340 or larger). The card crops to
  a fixed 168 px-tall band with `object-fit: cover`, so the centre stays visible.
- **Format:** `.jpg` (or swap the extension in the `<img src>` if you use `.webp`).
- **Size:** keep each file under ~200 KB; they are lazy-loaded.
- No code changes are needed — just match the filenames above. Until a file
  exists, the card shows a clean solid-navy panel instead of a broken image.
