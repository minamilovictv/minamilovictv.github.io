HOW TO ADD PHOTOS TO THE FORUM 2026 ARTICLE GALLERY
===================================================

The GEFund page (gefund.html) has a news article:
"WBF Takes Part in the Gender Equality Forum 2026 in Sarajevo".

Clicking the article card opens a pop-up window with the full text
and a picture gallery (carousel). This is where its photos come from.

HOW IT WORKS
------------
Just drop your photos into THIS folder and name them with plain
numbers, starting at 1, with the .jpg extension:

    1.jpg
    2.jpg
    3.jpg
    ...

Rules:
  * Start at 1 and count up with NO gaps (1, 2, 3, 4 ...).
    The page stops looking at the first missing number, so if you
    skip a number the later ones will not show.
  * .jpg, .jpeg, .png and .webp all work — you do NOT need to rename.
  * One photo is fine (name it 1.jpg) — the gallery simply shows it.
  * Add as many as you like (1 ... 30).
  * KEEP FILES SMALL: aim for under ~500 KB each (resize to about
    1600px on the long edge). Huge photos (5-10 MB) make the page
    slow to load, especially on phones.

That's it — no HTML editing needed. Refresh the page, open the
article, and the pictures appear with arrows, dots, thumbnails,
a slide counter and automatic sliding.

If this folder is empty, the gallery shows a tidy "Photos coming
soon" placeholder instead — nothing breaks.

OPTIONAL CAPTIONS
-----------------
To give a photo a caption, add a line to captions.txt (in this
folder), one caption per line, matching the photo order:

    Line 1  -> caption for 1.jpg
    Line 2  -> caption for 2.jpg
    ...

captions.txt is optional. No file = no captions, and that's fine.
