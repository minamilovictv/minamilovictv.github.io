As soon as the file exists, it replaces the coloured gradient + initials on the
matching card in move.html automatically. If a file is missing, the card falls
back to the gradient — nothing breaks.

Tips
----
- .jpg is expected. If you only have .png, either rename it to .jpg or tell me
  and I'll switch the card to .png.
- Landscape photos work best (the card area is ~4:3, roughly 400 x 220 px).
  Larger is fine — the image is cropped to fill and centred.
- Keep file sizes reasonable (ideally under ~300 KB each) so the page stays fast.
