HOW TO ADD PHOTOS TO THE GOVERNANCE PAGE CAROUSELS
==================================================

Each body on the Governance page (Conference of Ministers, Council of
Senior Officials, Executive Director, Secretariat) has its own picture
carousel. You can add ONE or MANY pictures to each — they will rotate
automatically.

There is one folder per section:

    assets/governance/ministers/     -> Conference of Ministers carousel
    assets/governance/council/       -> Council of Senior Officials carousel
    assets/governance/director/      -> Executive Director carousel
    assets/governance/secretariat/   -> Secretariat carousel
    assets/governance/chairmanship/  -> (optional, spare folder)

HOW IT WORKS
------------
Just drop your photos into the matching folder and name them with
plain numbers, starting at 1, with the .jpg extension:

    1.jpg
    2.jpg
    3.jpg
    ...

Rules:
  * Start at 1 and count up with NO gaps (1, 2, 3, 4 ...).
    The page stops looking at the first missing number, so if you
    skip a number the later ones will not show.
  * Use the .jpg extension (lower-case). If your photo is a .png or
    .jpeg, rename/convert it to .jpg first.
  * One photo is fine (name it 1.jpg) — the carousel simply shows it.
  * Add as many as you like (1.jpg ... 20.jpg).

That's it — no HTML editing needed. Refresh the page and the pictures
appear, with arrows, dots and automatic sliding.

If a folder is empty, the carousel shows a tidy "Add photos" placeholder
instead — nothing breaks.
